# Experiment Manager

Structured what-if analysis for validating changes, brainstorming experiments, and designing measurements.

## Getting Started

```bash
# Install
/plugin install experiment-manager@oeid-claude-plugins

# Learn what this plugin can do
/experiment-manager:introduce
```
