# Code Repository Manager

Manage code repository documentation — publish co-design docs to GitHub Wiki and GitHub Pages, rebuild navigation, and sync across targets.

## Getting Started

```bash
/code-repository-manager:introduce
```

## Skills (2)

| Category | Skill | What it does |
|---|---|---|
| **Intro** | `introduce` | Explain plugin capabilities and guide to the right skill |
| **Publish** | `update-docs` | Sync co-design documents to GitHub Wiki and GitHub Pages, rebuild navigation, commit and push |

## Requirements

- Git (for wiki repo and gh-pages branch management)
- zsh (sync scripts use zsh-specific features)
- GitHub Enterprise access (for wiki and pages targets)
