# NotePlan Templates

Maintain and manage NotePlan templates in the @Templates directory.

## Overview

This plugin helps you create, edit, organize, and maintain NotePlan templates. It understands NotePlan template syntax and conventions.

## Skills

### list-templates

**Usage:** `/noteplan-templates:list-templates`

List all available templates with:
- Template names and locations
- Categorization by folder or type
- Brief descriptions
- Last modified dates
- Usage guidance

### manage-templates

**Usage:** `/noteplan-templates:manage-templates`

Edit and maintain existing templates:
- Modify template content and structure
- Update frontmatter and metadata
- Reorganize templates
- Validate template syntax
- Standardize formatting

### create-template

**Usage:** `/noteplan-templates:create-template`

Create new templates following NotePlan conventions:
- Interactive template design
- Pattern-aware creation
- NotePlan feature integration (variables, tags, dates)
- Best practices application

## Features

- **Template Discovery**: Find and browse all templates
- **Smart Editing**: Maintain NotePlan syntax and conventions
- **Pattern Recognition**: Follows your existing template styles
- **Validation**: Ensures templates work correctly in NotePlan
