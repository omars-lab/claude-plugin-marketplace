# NotePlan Note Creator

Create new NotePlan notes following existing conventions and patterns.

## Overview

This plugin creates new notes that seamlessly integrate with your existing NotePlan structure by analyzing and following your established patterns for organization, formatting, emoji usage, and linking.

## Skills

### create-note

**Usage:** `/noteplan-note-creator:create-note`

Create structured notes with full context:
- Interactive note design
- Pattern analysis and application
- Appropriate template selection
- Location determination
- Connection establishment
- Convention following

**Note Types Supported:**
- Project notes
- Area notes (ongoing responsibilities)
- Resource notes (reference material)
- Meeting notes
- Custom note types

### quick-note

**Usage:** `/noteplan-note-creator:quick-note`

Rapidly create simple notes with minimal friction:
- Minimal questions
- Smart defaults
- Fast creation
- Basic structure
- Essential metadata

**Quick Note Types:**
- Simple notes
- Task lists
- Ideas
- References
- Meeting captures

## Features

- **Pattern-Aware**: Analyzes existing notes to match your style
- **Context-Intelligent**: Places notes in appropriate folders
- **Convention-Following**: Uses your emoji, tag, and naming patterns
- **Connection-Building**: Establishes links to related notes
- **Template-Integrated**: Uses templates when appropriate

## Pattern Recognition

Automatically detects and follows:
- Naming conventions
- Emoji usage patterns
- Tag taxonomy
- Section structure
- Frontmatter format
- Linking style
