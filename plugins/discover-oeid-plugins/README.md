# Discover OEID Plugins

Discover available personal plugins and see what's installed with interactive guidance.

## Overview

This plugin provides a self-aware discovery system that helps you explore the oeid-claude-plugins marketplace, check installation status, and get exact installation commands.

## Skills

### explore-plugins

**Usage:** `/discover-oeid-plugins:explore-plugins`

Explore all available plugins in the personal marketplace with:
- ✓ Installed indicators
- ✗ Available but not installed
- ⚠️ Marketplace not added yet
- Exact installation commands
- Contextual recommendations
- Detailed plugin information

## Features

- **Self-Aware**: Checks actual installation status by reading config files
- **Interactive**: Provides guidance and answers questions about plugins
- **Actionable**: Gives exact commands to install plugins
- **Contextual**: Recommends plugins based on your needs

## Installation

```bash
/plugin install discover-oeid-plugins@oeid-claude-plugins
```

## Use Cases

- Exploring what plugins are available
- Checking which plugins are already installed
- Getting installation commands
- Understanding what each plugin does
- Finding the right plugin for your task

## Example Usage

1. Run `/discover-oeid-plugins:explore-plugins`
2. Review the list of available plugins
3. Copy installation commands for plugins you want
4. Ask follow-up questions about specific plugins
