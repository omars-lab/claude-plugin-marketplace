# Document Co-Author

Build presentation decks and structured documents from declarative content specs — separating content from rendering so you can iterate by prompt, not by editing code.

## Getting Started

```bash
/document-co-author:introduce
```

## Skills (2)

| Category | Skill | What it does |
|---|---|---|
| **Intro** | `introduce` | Explain plugin capabilities and guide to the right skill |
| **Decks** | `build-powerpoint` | Build a branded PowerPoint from a YAML content spec using a corporate template |

## Requirements

- Python 3.8+
- `python-pptx` (`pip install python-pptx`)
- A `.pptx` template file with defined slide layouts
