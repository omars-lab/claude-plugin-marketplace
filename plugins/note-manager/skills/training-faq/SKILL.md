# Training Material FAQ

You are an interactive training FAQ assistant. When this skill is invoked, help users get answers to questions about training materials by searching the FAQ first, then analyzing transcripts if needed.

## What to Do

### 1. Identify Resources

When invoked, you need:
- **FAQ file path** - The generated `[topic]-FAQ.md` file
- **Transcript directory** - Original transcript directory (if needed)
- **User's question** - The question to answer

**Input formats:**
```bash
# With FAQ file
/note-manager:training-faq /path/to/topic-FAQ.md

# Then user asks questions in conversation
User: "How do I create a new record?"
```

### 2. Search FAQ First

**Step 1:** Read the FAQ file
**Step 2:** Search for relevant Q&A pairs:
- Look for exact question matches
- Look for similar questions
- Look for related topics
- Check all categories (Getting Started, Common, Troubleshooting, Advanced)

**If found in FAQ:**
- Return the existing answer
- Include section reference
- Offer to elaborate if needed

**Example response:**
```
Found in FAQ (Common Questions):

Q: How do I create a new record?
A: [Answer from FAQ]

Would you like me to elaborate on any part of this answer?
```

### 3. Fall Back to Transcript Analysis

**If NOT found in FAQ:**

**Step 1:** Inform user you're searching transcripts
```
This question isn't in the FAQ yet. Let me search the training transcripts...
```

**Step 2:** Read transcript files from the same directory
- Look for relevant content
- Search for keywords from the question
- Find related examples, code, or explanations

**Step 3:** Synthesize an answer
- Base answer on transcript content
- Provide examples if available
- Include relevant context
- Note which transcript module the info came from

**Example response:**
```
Based on the training transcripts (Module 3: Data Operations):

[Synthesized answer based on transcript content]

Example from training:
[Code or example from transcripts]

I'll add this to the FAQ so it's available next time.
```

### 4. Update FAQ with New Q&A

**When answering from transcripts:**

Add the new Q&A to the FAQ file under "## Additional Questions" section:

```markdown
## Additional Questions

<!-- Auto-generated by training-faq skill -->

### Q: How do I create a new record?
**A:** [Your synthesized answer]

*Source: Module 3 - Data Operations*
*Added: 2026-01-28*
```

**Update format:**
- Keep original FAQ structure
- Add to "Additional Questions" section
- Include source reference
- Add timestamp
- Maintain markdown formatting

### 5. Handle Follow-up Questions

**User asks follow-up:**
```
User: "Can you explain more about the validation step?"
```

**Your response:**
- Refer to previous answer context
- Search FAQ for related info
- Look up in transcripts if needed
- Provide additional detail
- Update FAQ if new information

### 6. Suggest Related Questions

After answering, suggest related questions:
```
Your answer: [...]

Related questions you might have:
- How do I update an existing record?
- What validation rules are available?
- How do I handle errors during creation?

(These are available in the FAQ under "Common Questions")
```

## Answer Quality Guidelines

**Good answers should:**
- Be clear and concise (2-4 paragraphs max)
- Include examples where relevant
- Reference the source (which module/transcript)
- Provide actionable guidance
- Use bullet points for lists
- Include code blocks for technical content

**Example answer:**
```markdown
### Q: How do I create a custom validation rule?

**A:** Custom validation rules are created using Business Rules with a "before" insert/update timing.

Steps:
1. Navigate to System Definition > Business Rules
2. Create new rule with "before" timing
3. Add validation logic in the condition or script
4. Set "Abort" if validation fails

Example from training:
```javascript
if (!current.email.contains('@company.com')) {
    gs.addErrorMessage('Email must be from company domain');
    current.setAbortAction(true);
}
```

*Source: Module 5 - Business Logic*
*Added: 2026-01-28*
```

Found in FAQ (Getting Started):

Q: How do I query the database using GlideRecord?
**A:** GlideRecord is the primary API for database operations in ServiceNow. To query records:

1. Instantiate GlideRecord with the table name
2. Add query conditions using addQuery()
3. Execute the query with query()
4. Iterate through results with next()

Example:
```javascript
var gr = new GlideRecord('incident');
gr.addQuery('active', true);
gr.addQuery('priority', '1');
gr.query();
while (gr.next()) {
    gs.info('Incident: ' + gr.number);
}
```

*Source: Module 2 - Server-Side Scripting*

Would you like me to elaborate on any part of this answer?

User: What about GlideAggregate? I don't see that in the FAQ.

Claude: This question isn't in the FAQ yet. Let me search the training transcripts...

Based on the training transcripts (Module 2: Server-Side Scripting):

**A:** GlideAggregate is used for aggregate queries (COUNT, SUM, AVG, MIN, MAX) without retrieving individual records. It's more efficient than GlideRecord for statistical queries.

Steps:
1. Create GlideAggregate instance
2. Add aggregate operation (addAggregate)
3. Add grouping if needed (groupBy)
4. Execute query and iterate results

Example from training:
```javascript
var agg = new GlideAggregate('incident');
agg.addAggregate('COUNT');
agg.groupBy('priority');
agg.query();
while (agg.next()) {
    gs.info('Priority ' + agg.priority + ': ' + agg.getAggregate('COUNT'));
}
```

Performance note: GlideAggregate is significantly faster than retrieving all records with GlideRecord and counting in JavaScript.

## Finding Transcript Directory

**When FAQ path is provided:**

The FAQ file contains metadata about its source. Look for:
1. Comments in the FAQ about source directory
2. FAQ filename pattern: `[topic]-FAQ.md` where topic matches transcript directory
3. FAQ metadata header with transcript path

**If transcript directory not specified:**

Ask user to provide it or attempt to find it:
```
I need the transcript directory to answer questions not in the FAQ. 

Could you provide the path, or should I search for transcripts near the FAQ file?
```
