# NotePlan Structure Analyzer

Analyze NotePlan folder structure, emoji usage, and suggest enhancements.

## Overview

This plugin examines your NotePlan organization and provides insights, analysis, and actionable recommendations for improvement.

## Skills

### analyze-structure

**Usage:** `/noteplan-structure-analyzer:analyze-structure`

Comprehensive analysis of your NotePlan system:
- Folder hierarchy mapping
- Emoji usage patterns
- Tag taxonomy and distribution
- Content organization patterns
- Daily notes health
- Linking patterns and density
- Statistical summaries

**Analysis Depth Options:**
- Quick: Overview and folder structure
- Standard: Full analysis (default)
- Deep: Includes trends and detailed insights

### suggest-improvements

**Usage:** `/noteplan-structure-analyzer:suggest-improvements`

Actionable improvement recommendations:
- Quick wins (immediate impact)
- Strategic improvements (long-term value)
- Priority matrix (impact vs. effort)
- Implementation roadmap
- Best practices to adopt
- Specific step-by-step guidance

## Features

- **Comprehensive Analysis**: Examines all aspects of organization
- **Visual Reporting**: Clear, structured output with charts
- **Pattern Detection**: Identifies organizational systems in use
- **Actionable Insights**: Practical recommendations, not generic advice
- **Prioritization**: Impact vs. effort analysis

## Analysis Categories

1. **Folder Structure**: Hierarchy, depth, organization patterns
2. **Emoji Usage**: Patterns, consistency, meaning
3. **Tagging**: Tag taxonomy, frequency, optimization
4. **Content Organization**: Note types, naming, frontmatter
5. **Linking Patterns**: Note connections, isolated notes
6. **Daily Notes**: Processing health, backlog status
